(구)밑줄 태그와 취소선 태그

u 태그는 과거 밑줄을 긋는 용도로 사용되었으나
현재는 CSS 효과와 함께철자 오류 등을 강조하는 용도로 사용됍니다
s 태그는 더 이상 유효하지 않은 정보를 취소선과 함께 나타내죠.
